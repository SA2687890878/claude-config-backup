## 组件关系

```
CLAUDE.md（项目指令）
    │
    ├── rules/（编码规范）
    │   ├── csharp.md        → C# 编码约束
    │   ├── git.md           → Git 提交规范
    │   ├── security.md      → 安全规则
    │   └── ...
    │
    ├── skills/（工作流组件）
    │   ├── brainstorming/          → 需求探索
    │   ├── writing-plans/          → 实现规划
    │   ├── verification/           → 完成前验证
    │   ├── safe-modification/      → 安全修改
    │   └── ...
    │
    ├── commands/（自定义命令）
    │   ├── feature-development.md  → 功能开发流程
    │   ├── bug-fix.md             → Bug 修复流程
    │   └── ...
    │
    └── hooks/（生命周期钩子）
        ├── PreToolUse              → 执行前检查
        │   ├── Secret Guard        → 密钥检测
        │   ├── Write Guard         → 路径安全
        │   ├── Impact Guard        → 影响提醒
        │   └── Git Commit Review   → Git 安全检查
        │
        └── PostToolUse             → 执行后检查
            ├── CS Guard            → 语法检查
            ├── Quality Guard       → 质量检查
            ├── Build Guard         → 构建提示
            └── SQLite Index Update → 自动索引更新（加密源码项目）
```

## 数据流

```
用户输入
    │
    ├─→ 触发词匹配（workflows.md）
    │       │
    │       └─→ 选择工作流（commands/）
    │               │
    │               └─→ 执行 Phase 1 → Phase 2 → ...
    │                       │
    │                       ├─→ 调用 skills/（工作流组件）
    │                       ├─→ 遵守 rules/（编码规范）
    │                       └─→ 触发 hooks/（生命周期检查）
    │
    ├─→ Token 优化
    │       ├─→ RTK Hook（CLI 输出压缩）
    │       ├─→ CodeGraph（代码结构探索）
    │       └─→ Context-mode（大文件处理）
    │
    └─→ 输出结果
            ├─→ 代码变更
            ├─→ 审查报告
            └─→ 构建验证
```

## 设计原则

| 原则 | 说明 |
|------|------|
| **分层防御** | PreToolUse 拦截危险操作，PostToolUse 检查质量 |
| **自动化优先** | Hook 自动执行，减少人工检查 |
| **Token 效率** | 多层优化，减少不必要的 token 消耗 |
| **官方规范** | 严格遵循 Claude Code 官方规范 |
| **渐进增强** | 核心功能必须有，高级功能可选 |

---

## 快速理解

**一句话**：用户输入 → 触发词匹配 → 选择工作流 → 执行流程 → Hook 检查 → Token 优化 → 输出结果

**核心组件**：
- `CLAUDE.md`：告诉 Claude "这是什么项目"
- `rules/`：告诉 Claude "必须遵守什么"
- `skills/`：告诉 Claude "遇到这种情况怎么做"
- `commands/`：告诉 Claude "这个流程怎么走"
- `hooks/`：自动检查"有没有违规"

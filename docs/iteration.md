# 自动迭代机制

## 迭代循环

```
┌─────────────────────────────────────────────────────────────┐
│ Plan（计划）                                                  │
│ - 分析当前状态                                                │
│ - 确定改进目标                                                │
│ - 制定迭代计划                                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Do（执行）                                                    │
│ - 按计划执行工作流                                            │
│ - 记录执行过程                                                │
│ - 收集问题和反馈                                              │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Check（检查）                                                 │
│ - 审查执行结果                                                │
│ - 分析问题根因                                                │
│ - 评估改进效果                                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Act（改进）                                                   │
│ - 更新工作流配置                                              │
│ - 优化 Agent 角色定义                                         │
│ - 完善文档和模板                                              │
└─────────────────────────────────────────────────────────────┘
                            ↓
                     （循环继续）
```

## 迭代触发条件

### 自动触发

| 条件 | 触发动作 |
|------|---------|
| 工作流执行失败 | 分析失败原因，优化工作流 |
| 审查通过率 < 80% | 分析常见问题，完善审查清单 |
| Agent 调用超时 | 优化 Agent 提示词，简化任务 |
| 用户反馈问题 | 收集反馈，设计改进方案 |

### 手动触发

| 触发词 | 动作 |
|--------|------|
| 优化工作流 | 分析当前工作流，设计改进方案 |
| 改进 Agent | 优化 Agent 角色定义和提示词 |
| 更新文档 | 完善文档和模板 |
| 审计回顾 | 执行周期审计，生成报告 |

## 迭代内容

### 工作流迭代

**迭代对象：**
- 工作流步骤
- Agent 角色定义
- 触发词映射
- 输出格式

**迭代方式：**
1. 收集执行数据和用户反馈
2. 分析问题和改进点
3. 设计改进方案
4. 更新 CLAUDE.md 和文档
5. 验证改进效果

**示例：**
```
问题：功能开发流程中，需求分析师和架构师的职责有重叠
改进：明确需求分析师只负责需求澄清，架构师只负责技术方案审查
验证：下次功能开发流程执行顺利
```

### Agent 迭代

**迭代对象：**
- Agent 职责定义
- Agent 提示词
- Agent 自检清单
- Agent 输出格式

**迭代方式：**
1. 收集 Agent 执行数据
2. 分析 Agent 表现
3. 优化 Agent 定义
4. 测试优化效果

**示例：**
```
问题：实现者经常忘记注册依赖注入
改进：在实现者自检清单中增加"依赖注入是否注册？"
验证：后续实现中 DI 注册遗漏减少
```

### 文档迭代

**迭代对象：**
- 工作流文档
- Agent 角色文档
- 接口契约模板
- 审查清单

**迭代方式：**
1. 收集文档使用反馈
2. 分析文档问题
3. 更新文档内容
4. 验证文档可用性

**示例：**
```
问题：接口契约模板缺少错误处理示例
改进：在模板中增加错误处理示例
验证：跨项目开发时接口对接更顺畅
```

## 自动化迭代工具

### Workflow 工具

使用 Workflow 工具实现自动化迭代：

```javascript
// 计划阶段
const plan = await agent('分析当前状态，确定改进目标，制定迭代计划')

// 执行阶段
await workflow('execute-iteration', { plan })

// 检查阶段
const review = await agent('审查执行结果，分析问题根因，评估改进效果')

// 改进阶段
await agent('更新工作流配置，优化 Agent 角色定义，完善文档和模板')
```

### 迭代脚本

```powershell
# 检查迭代条件
function Test-IterationCondition {
    param(
        [string]$Condition,
        [int]$Threshold
    )
    
    switch ($Condition) {
        "workflow-failure" {
            # 检查工作流失败率
            return $false
        }
        "review-pass-rate" {
            # 检查审查通过率
            return $true
        }
        "agent-timeout" {
            # 检查 Agent 超时
            return $false
        }
        default {
            return $false
        }
    }
}

# 执行迭代
function Start-Iteration {
    param(
        [string]$IterationType
    )
    
    Write-Host "开始迭代: $IterationType"
    
    # Plan
    Write-Host "1. 分析当前状态..."
    
    # Do
    Write-Host "2. 执行改进..."
    
    # Check
    Write-Host "3. 检查效果..."
    
    # Act
    Write-Host "4. 更新配置..."
    
    Write-Host "迭代完成: $IterationType"
}
```

## 迭代最佳实践

### 1. 小步快跑

- 每次迭代只改一个点
- 快速验证效果
- 及时调整方向

### 2. 数据驱动

- 收集执行数据
- 分析问题根因
- 基于数据决策

### 3. 持改进进

- 定期回顾
- 持续优化
- 不追求完美

### 4. 记录沉淀

- 记录迭代过程
- 沉淀经验教训
- 形成知识库

### 5. 用户参与

- 收集用户反馈
- 纳入迭代计划
- 验证改进效果

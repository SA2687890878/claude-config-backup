# 配置文件审查清单

## CRITICAL — 生产必炸

### 密钥泄露
- [ ] 连接字符串中的密码是否硬编码
- [ ] API Key 是否硬编码
- [ ] Token 是否硬编码
- [ ] 私钥是否硬编码
- [ ] 是否有注释掉的密钥（可能被误恢复）

### 敏感信息
- [ ] 个人身份信息（PII）是否暴露
- [ ] 内部 IP/域名是否暴露
- [ ] 调试信息是否关闭
- [ ] 详细错误信息是否关闭

## HIGH — 很可能出问题

### CORS 配置
- [ ] AllowedOrigins 是否过宽（不用 *）
- [ ] AllowedMethods 是否必要
- [ ] AllowedHeaders 是否必要
- [ ] AllowCredentials 是否正确配置

### 认证配置
- [ ] JWT 过期时间是否合理
- [ ] 密码强度要求是否配置
- [ ] 锁定策略是否配置
- [ ] HTTPS 是否强制

### 数据库配置
- [ ] 连接池大小是否合理
- [ ] 连接超时是否配置
- [ ] 命令超时是否配置
- [ ] 重试策略是否配置

## MEDIUM — 可能出问题

### 日志配置
- [ ] 生产环境日志级别是否合适（Info/Warning，不是 Debug）
- [ ] 敏感数据是否脱敏
- [ ] 日志轮转是否配置
- [ ] 日志大小限制是否配置

### 缓存配置
- [ ] 缓存过期时间是否合理
- [ ] 缓存大小限制是否配置
- [ ] 缓存键命名是否清晰

### 文件上传
- [ ] 文件大小限制是否配置
- [ ] 允许的文件类型是否白名单
- [ ] 上传路径是否安全

## LOW — 代码质量

- [ ] 配置项是否有注释
- [ ] 环境变量是否有默认值
- [ ] 配置结构是否清晰
- [ ] 是否有未使用的配置项

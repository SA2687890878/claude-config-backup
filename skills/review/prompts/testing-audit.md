# 测试审计提示词

使用 review skill 的**测试模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注测试是否提供真实的代码库信心。

## 审计维度（参见原则 8.1-8.5）

### 覆盖质量（不是数量）
- 关键路径没有测试覆盖
- 错误处理路径没有测试覆盖
- 输入验证的边界情况
- 边界条件
- 故障模式测试

### 测试类型
- 核心逻辑的单元测试覆盖
- 外部接口的集成测试覆盖
- API 的端到端测试覆盖
- 性能测试覆盖
- 安全测试覆盖

### 测试质量
- 测试是否有意义的断言
- 测试是否独立
- 测试是否可重复
- 测试是否快速

### 测试维护
- 测试是否易于维护
- 测试是否有文档
- 测试是否有版本控制
- 测试是否有 CI/CD 集成

# 可观测性审计提示词

使用 review skill 的**可观测性模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注运维人员是否能在真实的生产故障下理解、调试和恢复系统。

## 审计维度

### 日志
- 关键状态转换、故障和安全敏感操作缺少日志
- 需要结构化字段进行搜索和关联的地方使用非结构化日志
- 日志缺少请求 ID、追踪 ID、用户/账户 ID、作业 ID 或操作名称
- 错误日志丢失原因、堆栈或相关上下文
- 敏感数据以明文记录

### 指标
- 没有请求量、延迟、错误率、饱和度、队列深度或工作滞后指标
- 在需要直方图/仪表的地方使用计数器，反之亦然
- 指标缺少维度（端点、状态码、租户）
- 指标命名不一致

### 追踪
- 没有分布式追踪
- 追踪缺少关键操作
- 追踪缺少上下文传播
- 追踪采样策略不当

### 告警
- 告警规则缺失
- 告警阈值不当
- 告警通知不当
- 告警处理流程不当

### 健康检查
- 缺少健康检查端点
- 健康检查不全面
- 健康检查结果不准确
- 健康检查未集成到部署流程

# 稳定性审计提示词

使用 review skill 的**稳定性模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注可靠性、运行时安全、状态一致性和故障恢复。

## 审计维度（参见原则 4.4, 6.1-6.4, 10.1-10.4）

### 崩溃和 Panic 路径
- 直接调用 `panic!`、`unwrap()`、`expect()`、`assert!`
- 无边界检查的索引
- 除以零
- 空指针 / nil 解引用风险
- 无类型检查的向下转换
- 整数溢出 / 下溢

### 错误处理
- 静默吞掉的错误
- 过于宽泛的异常捕获
- 错误信息丢失上下文
- 错误未记录日志
- 错误未传播

### 并发安全
- 共享状态无锁保护
- 锁粒度不合适
- 死锁风险
- 异步操作处理不当
- 竞态条件

### 资源管理
- 资源泄露（连接、文件、内存）
- 资源未正确释放
- 资源池耗尽
- 超时设置不当

### 状态一致性
- 状态更新非原子性
- 状态更新顺序错误
- 状态更新失败未回滚
- 状态更新未记录日志

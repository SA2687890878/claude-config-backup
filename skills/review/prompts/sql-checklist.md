# SQL 代码审查清单

## CRITICAL — 生产必炸

### SQL 注入
- [ ] 是否使用参数化查询
- [ ] 是否有字符串拼接 SQL
- [ ] 存储过程是否安全
- [ ] 动态 SQL 是否安全

### 数据丢失
- [ ] DELETE/UPDATE 是否有 WHERE 条件
- [ ] 是否有事务保护
- [ ] 是否有备份策略
- [ ] 是否有回滚策略

### 性能问题
- [ ] 是否有全表扫描
- [ ] 是否缺少索引
- [ ] 是否有 N+1 查询
- [ ] 是否有锁竞争

## HIGH — 很可能出问题

### 数据完整性
- [ ] 是否有外键约束
- [ ] 是否有唯一约束
- [ ] 是否有检查约束
- [ ] 是否有默认值

### 并发问题
- [ ] 是否有死锁风险
- [ ] 是否有锁超时
- [ ] 是否有乐观锁
- [ ] 是否有悲观锁

## MEDIUM — 可能出问题

### 代码质量
- [ ] SQL 是否可读
- [ ] 是否有重复 SQL
- [ ] 是否有复杂 JOIN
- [ ] 是否有子查询

### 维护性
- [ ] 是否有存储过程文档
- [ ] 是否有索引文档
- [ ] 是否有表结构文档
- [ ] 是否有数据字典

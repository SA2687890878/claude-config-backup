# 降级审计提示词

使用 review skill 的**降级模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注"无异议降级" — 静默降级、默认值、空 catch 块、兼容性分支和可能隐藏真实错误的防御性代码。

## 审查领域

### 静默降级
- `||` / `or()` / `or_else()` 默认链静默激活。
- 配置缺失时降级到硬编码的开发/空值。
- Optional/Maybe 使用默认值解包，忽略错误。
- match/switch 中的默认情况返回魔法值而不记录。

### 空捕获/忽略的错误
- 空的 `catch {}` / `except: pass` 块。
- `// TODO: handle error` 没有后续。
- 错误返回函数的返回值用 `void` / `let _ =` 丢弃。
- 异常被吞没。

### 防御性代码
- 过度防御性编程
- 不必要的空检查
- 不必要的类型检查
- 不必要的边界检查

### 兼容性分支
- 兼容性分支未记录
- 兼容性分支未测试
- 兼容性分支未清理

# 通用代码审查清单

## CRITICAL — 生产必炸

### 空指针/空值
- [ ] 返回值是否检查 null
- [ ] 集合操作前是否检查 null/Empty
- [ ] 字符串操作前是否检查 null
- [ ] 可空类型是否正确使用

### 资源泄露
- [ ] IDisposable 对象是否正确释放
- [ ] 文件流是否正确关闭
- [ ] 数据库连接是否正确释放
- [ ] HTTP 客户端是否正确使用

### 注入风险
- [ ] SQL 注入风险
- [ ] XSS 风险
- [ ] 命令注入风险
- [ ] 路径遍历风险

## HIGH — 很可能出问题

### 异常处理
- [ ] 异常是否被吞掉
- [ ] 异常类型是否精确
- [ ] 资源释放是否在 finally 块
- [ ] 是否用异常做流程控制

### 并发安全
- [ ] 共享状态是否有锁保护
- [ ] 锁的粒度是否合适
- [ ] 是否有死锁风险
- [ ] 异步操作是否正确处理

## MEDIUM — 可能出问题

### 代码质量
- [ ] 方法是否过长（>50行）
- [ ] 类是否过大（>500行）
- [ ] 是否有重复代码
- [ ] 命名是否规范

### 性能问题
- [ ] 是否有 N+1 查询
- [ ] 是否有不必要的循环
- [ ] 是否有内存泄露
- [ ] 是否有性能瓶颈

## LOW — 代码质量

### 可维护性
- [ ] 注释是否充分
- [ ] 文档是否完整
- [ ] 测试是否覆盖
- [ ] 代码是否可读

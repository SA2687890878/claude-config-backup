# 可访问性和 UX 正确性审计提示词

使用 review skill 的**可访问性模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注浏览器/客户端 UI 工作流在键盘、屏幕阅读器、响应式、加载、空和错误状态下是否保持可用、可理解和正确。

## 审查领域

### 语义结构
- 从非语义元素构建的交互元素没有角色或键盘处理。
- 没有标签或可访问名称的输入。
- 仅图标控件没有可访问标签。
- 标题、地标、对话框、选项卡和菜单没有语义表示。
- 状态消息未通知辅助技术。

### 键盘和焦点
- 关键工作流无法通过键盘访问。
- 焦点丢失、被困不正确或在模态/路由更改后未恢复。
- 选项卡顺序不遵循视觉顺序。
- 自定义控件没有键盘交互。
- 焦点指示器缺失或不可见。

### 屏幕阅读器
- 图像没有替代文本。
- 动态内容更改未宣布。
- 表单错误未关联到字段。
- 复杂小部件缺少 ARIA 属性。
- 实时区域未正确配置。

### 响应式和视口
- 内容在小视口中被截断或隐藏。
- 触摸目标太小（<44px）。
- 水平滚动出现在窄视口中。
- 媒体查询未覆盖常见断点。

### 加载和错误状态
- 加载状态未传达给辅助技术。
- 错误消息未关联到表单字段。
- 空状态未提供指导。
- 网络错误未提供重试选项。

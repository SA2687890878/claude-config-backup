# 隐私和数据治理审计提示词

使用 review skill 的**隐私模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注个人数据处理、数据最小化、保留、删除、导出、日志、访问边界和隐私相关治理。

## 审计维度

### 数据清单和分类
- 收集 PII 或敏感数据没有明确目的
- 存储个人数据字段没有分类或所有权
- 敏感字段复制到分析、日志、缓存、队列或导出中
- 测试夹具或示例包含真实的个人数据
- 派生标识符可以重新识别用户

### 数据最小化
- 收集或持久化当前行为不需要的字段
- 发送完整记录，而只需要 ID 或聚合
- 日志记录敏感数据
- 缓存敏感数据
- 导出敏感数据

### 数据保留
- 没有数据保留策略
- 数据保留策略未执行
- 数据保留策略未记录
- 数据保留策略未审计

### 数据删除
- 没有数据删除流程
- 数据删除流程未测试
- 数据删除流程未记录
- 数据删除流程未审计

### 数据导出
- 没有数据导出流程
- 数据导出流程未测试
- 数据导出流程未记录
- 数据导出流程未审计

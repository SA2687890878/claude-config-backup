# 文档审计提示词

使用 review skill 的**文档模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注外部文档、内部文档、设置说明和运维指导是否与代码匹配并减少真实的交付风险。

## 审计维度

### 用户和运维文档
- README 或文档描述的命令、行为、配置或 API 不再匹配代码
- 缺少设置、安装、升级、回滚或部署步骤
- 缺少已知故障模式的故障排除指导
- 运维文档缺少健康检查、告警处理、备份/恢复或事件响应步骤

### 开发者文档
- 没有非显而易见模块边界的架构概述
- 缺少贡献、测试、构建或本地环境说明
- 生成的代码、迁移或脚本没有安全使用说明

### API 文档
- 公共 API 缺少文档
- API 文档不准确
- API 文档缺少示例
- API 文档缺少错误码说明

### 代码文档
- 复杂算法缺少注释
- 业务逻辑缺少注释
- 临时方案缺少注释
- 已知问题缺少注释

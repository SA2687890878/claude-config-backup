# 配置文件审查清单

## CRITICAL — 生产必炸

### 密钥泄露
- [ ] 是否有硬编码的密钥/密码/token
- [ ] 是否有 API 密钥泄露
- [ ] 是否有数据库密码泄露
- [ ] 是否有证书泄露

### 敏感信息
- [ ] 是否有个人信息泄露
- [ ] 是否有内部 IP 地址泄露
- [ ] 是否有内部域名泄露
- [ ] 是否有内部路径泄露

## HIGH — 很可能出问题

### 配置安全
- [ ] 配置文件是否加密
- [ ] 配置文件是否有访问控制
- [ ] 配置文件是否有版本控制
- [ ] 配置文件是否有备份

### 环境分离
- [ ] 开发/测试/生产环境是否分离
- [ ] 环境配置是否隔离
- [ ] 环境配置是否加密
- [ ] 环境配置是否版本控制

## MEDIUM — 可能出问题

### 配置管理
- [ ] 配置是否有文档
- [ ] 配置是否有默认值
- [ ] 配置是否有验证
- [ ] 配置是否有监控

### 配置质量
- [ ] 配置是否清晰
- [ ] 配置是否一致
- [ ] 配置是否易于维护
- [ ] 配置是否易于扩展

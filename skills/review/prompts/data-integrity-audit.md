# 数据完整性审计提示词

使用 review skill 的**数据完整性模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注系统在故障、重试、并发和升级下是否保持正确、持久和可恢复的数据。

## 审计维度

### 事务边界
- 多步写入没有事务或等效原子性保证
- 在事务打开时执行外部 I/O
- 后续操作失败时的部分写入
- 序列化/冲突错误缺少事务重试
- 业务不变量分散在应用程序代码和数据库约束中

### 幂等性和重试
- POST/作业/消息处理器不安全重试
- 重复提交创建重复记录或副作用
- 缺少幂等键
- 重试策略不当

### 数据一致性
- 数据不一致
- 数据重复
- 数据丢失
- 数据损坏

### 迁移安全
- 迁移脚本不安全
- 迁移脚本不可回滚
- 迁移脚本未测试
- 迁移脚本未备份

### 备份和恢复
- 备份策略缺失
- 备份未测试
- 恢复流程未文档化
- 恢复时间不可接受

# 成本和资源经济审计提示词

使用 review skill 的**成本模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注计算、存储、网络、队列、后台作业、缓存、可观测性、外部 API 和 LLM/模型使用带来的真实成本风险。

## 审查领域

### 无界工作
- 用户控制的输入可以触发昂贵的循环、查询、渲染、导出或批处理作业。
- 后台任务永远重试或无预算地扇出。
- 队列、缓存、历史记录、日志或追踪无保留限制地增长。
- Cron/定时作业不必要地扫描完整数据集。
- 工作被重复，而不是记忆化或去重。

### 外部 API 和 LLM 成本
- LLM/API 调用缺少令牌、请求或并发预算。
- 重复提示、嵌入、翻译或丰富的缓存/去重。
- 没有成本监控或告警。
- 没有成本预算或限制。

### 资源使用
- 计算资源使用不当
- 存储资源使用不当
- 网络资源使用不当
- 缓存资源使用不当

### 成本优化
- 未使用批量操作
- 未使用缓存
- 未使用压缩
- 未使用索引

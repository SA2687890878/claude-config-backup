# 发布审计提示词

使用 review skill 的**发布模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注此项目是否可以安全发布、安装、升级和回滚。

## 审计维度（参见原则 9.1-9.3：配置和环境）

### CI/CD 流水线
- CI 中运行什么检查？（lint、类型检查、测试、构建、安全扫描）
- 合并前有门禁吗？发布前呢？
- 构建矩阵（OS、架构、语言版本）
- 产物缓存和可重复性
- CI 速度 — 是否阻碍频繁发布？

### 版本管理
- 版本方案（semver、基于日期、基于提交）
- 版本定义在哪里以及如何定义
- 版本号是否一致
- 版本号是否易于理解

### 发布流程
- 发布步骤是否明确
- 发布时间是否合适（避开高峰期）
- 监控方案是否就绪
- 告警方案是否就绪

### 回滚方案
- 回滚步骤是否明确
- 回滚时间是否可接受
- 数据回滚是否可行
- 回滚后验证是否可行

### 文档
- 变更日志是否更新
- API 文档是否更新（如有接口变更）
- 用户文档是否更新（如有功能变更）

# 供应链和可重复性审计提示词

使用 review skill 的**供应链模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注依赖来源、构建可重复性、产物完整性、CI 固定、发布签名、SBOM 和供应链攻击面。

## 审查领域

### 依赖来源
- 从可变分支、未固定的 Git 引用或未认证的 URL 拉取依赖。
- 内部包名称容易受到依赖混淆攻击。
- 安装脚本、构建脚本或 postinstall 钩子执行未审查的代码。
- 维护或所有权不明确的传递依赖。
- 在安装/构建期间下载的原生二进制文件没有验证。

### 锁文件和可重复性
- 应用/服务缺少或忽略锁文件。
- CI 中未强制执行锁文件。
- 锁文件未提交到版本控制。
- 锁文件未定期更新。

### 构建完整性
- 构建产物未签名。
- 构建环境未固定。
- 构建过程未记录。
- 构建结果未验证。

### 发布安全
- 发布流程未记录。
- 发布流程未审计。
- 发布流程未自动化。
- 发布流程未测试。

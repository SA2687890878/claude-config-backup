# 前端状态审计提示词

使用 review skill 的**前端状态模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注前端状态管理、组件架构和 UI 数据流。此模式适用于具有浏览器/客户端 UI 的项目。

## 审查领域

### 组件大小
- 超过 400 行的单文件组件。
- 处理数据获取、转换、渲染和事件处理的组件。
- 职责过多的组件（UI 的 SRP 违规）。
- 超过 100 行的渲染函数/方法。

### 状态重复和同步
- 同一数据存储在多个存储或组件状态中。
- URL 参数、存储状态和组件本地状态之间的手动同步。
- 已经在存储中可用的数据的 `props`。
- 状态更新不一致。

### 数据流
- 数据流不清晰
- 数据流不一致
- 数据流难以追踪
- 数据流难以调试

### 副作用
- 副作用未清理
- 副作用顺序不当
- 副作用依赖不当
- 副作用未处理错误

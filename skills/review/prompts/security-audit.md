# 安全审计提示词

使用 review skill 的**安全模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

仅关注安全相关风险。

## 审计维度（参见原则 4.6：最小权限）

### 认证和授权
- 应用程序如何识别用户？
- 它如何确定每个用户可以做什么？
- 用户能否访问他们不应该访问的资源？
- 是否有硬编码的凭据、令牌或 API 密钥？
- 会话如何管理？令牌生命周期？

### 输入和输出
- 注入向量（命令、SQL、NoSQL、LDAP、模板）
- 文件操作中的路径遍历
- 文件上传的内容类型验证
- 文件下载的路径泄露
- 输出编码（XSS 防护）

### 密钥和配置
- 密钥是否硬编码在代码中？
- 密钥是否存储在版本控制中？
- 密钥是否有轮换策略？
- 配置是否有访问控制？

### 依赖安全
- 是否有已知漏洞的依赖？
- 依赖是否有安全更新？
- 依赖来源是否可信？

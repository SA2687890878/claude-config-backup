# 性能审计提示词

使用 review skill 的**性能模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注真实的瓶颈，而不是过早的微优化。

## 审计维度（参见原则 10.2：无界资源）

### 热点路径
- 请求处理器延迟
- 内循环性能
- 热点路径上的分配频率
- 关键路径上的序列化/反序列化

### 数据访问
- 数据库查询模式（N+1、缺少索引、全表扫描）
- 缓存命中率
- 连接池利用率
- 批量操作优化

### 内存管理
- 内存分配频率
- 内存泄露
- 大对象分配
- GC 压力

### I/O 操作
- 文件 I/O 效率
- 网络 I/O 效率
- 序列化/反序列化效率
- 压缩/解压缩效率

### 并发处理
- 线程池配置
- 异步操作效率
- 并发控制
- 资源竞争

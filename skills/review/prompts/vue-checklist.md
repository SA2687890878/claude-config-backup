# Vue 2 代码审查清单

## CRITICAL — 生产必炸

### XSS 风险
- [ ] v-html 是否使用安全（内容是否可信）
- [ ] 动态 URL 是否验证（javascript: 协议）
- [ ] 用户输入是否正确转义
- [ ] 模板表达式是否安全

### 响应式问题
- [ ] 对象新增属性是否使用 Vue.set
- [ ] 数组修改是否使用变异方法
- [ ] 计算属性是否有副作用
- [ ] watch 是否正确处理异步

### 组件安全
- [ ] props 是否验证
- [ ] 事件是否正确解绑
- [ ] 定时器是否正确清理
- [ ] 全局事件是否正确清理

## HIGH — 很可能出问题

### 性能问题
- [ ] v-for 是否有唯一 key
- [ ] 是否有不必要的重新渲染
- [ ] 计算属性是否缓存
- [ ] 是否有内存泄露

### 代码质量
- [ ] 组件是否过大（>300行）
- [ ] 是否有重复逻辑
- [ ] 命名是否规范
- [ ] 注释是否充分

## MEDIUM — 可能出问题

### 最佳实践
- [ ] 是否使用单文件组件
- [ ] 是否正确使用生命周期钩子
- [ ] 是否正确使用 mixins
- [ ] 是否正确使用插槽

### 可维护性
- [ ] 组件职责是否单一
- [ ] 是否有清晰的数据流
- [ ] 是否有清晰的事件流
- [ ] 是否有清晰的错误处理

# 测试真实性审计提示词

使用 review skill 的**测试真实性模式**。

共享设置、覆盖度、报告模板在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注测试是否提供**真实信心**还是只是绿色对勾。这不是关于覆盖率百分比 — 而是关于测试是否会捕获真实错误。

## 审查领域

### 过度 Mock
- Mock 除被测试函数之外的所有内容的测试。
- 返回固定数据且从不执行真实行为的 Mock。
- 验证 Mock 被调用的 Mock 断言（测试 Mock 框架，而不是代码）。
- 比被测试代码更复杂的 Mock 设置。

### 测试实现而不是行为
- 断言内部状态、私有方法或中间值的测试。
- 在重构不改变外部行为时失败的测试。
- 过度了解函数内部工作原理的测试。

### 测试隔离
- 测试依赖外部状态
- 测试依赖测试顺序
- 测试依赖测试数据
- 测试依赖测试环境

### 测试质量
- 测试没有有意义的断言
- 测试没有覆盖边界情况
- 测试没有覆盖错误路径
- 测试没有覆盖并发场景

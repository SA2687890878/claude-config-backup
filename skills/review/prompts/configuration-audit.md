# 配置审计提示词

使用 review skill 的**配置模式**。

共享设置、覆盖度、报告模板、HTML 和 lint 规则在 `references/report-format.md` 中；在生成报告前加载该参考文件。

关注配置正确性、验证、环境分离、功能开关卫生和安全的运行时默认值。

## 审计维度

### 配置模式和验证
- 启动时未验证必需的配置值
- 配置作为原始字符串解析，没有类型/模式验证
- 无效值在请求处理期间失败，而不是快速失败
- 配置默认值分散在多个文件中
- 文件、环境变量、CLI 标志和运行时覆盖之间没有明确优先级

### 安全默认值
- 开发默认值可在生产中使用
- 接受空或占位符密钥
- 默认值不安全
- 默认值未记录

### 环境分离
- 开发/测试/生产环境未分离
- 环境配置未隔离
- 环境配置未加密
- 环境配置未版本控制

### 功能开关
- 功能开关未清理
- 功能开关未记录
- 功能开关未测试
- 功能开关未监控

### 配置管理
- 配置未版本控制
- 配置未备份
- 配置未审计
- 配置未加密

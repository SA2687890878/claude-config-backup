# 证据要求

## 原则

每个发现都必须有证据支持。不能只是说"可能有问题"，必须给出具体证据。

## 证据类型

1. **代码位置** — 具体文件和行号
2. **代码片段** — 相关代码
3. **问题描述** — 具体问题是什么
4. **影响分析** — 会导致什么后果
5. **修复建议** — 如何修复

## 证据格式

```
【问题】文件:行号
代码：[代码片段]
问题：[问题描述]
影响：[影响分析]
修复：[修复建议]
```

## 禁止

1. **禁止模糊描述** — "可能有问题"
2. **禁止无证据** — 只说结论不说依据
3. **禁止猜测** — 必须基于实际代码

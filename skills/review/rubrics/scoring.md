# 评分标准

## 原则

评分是**基于判断，不是基于公式**。AI 根据收集的证据，对每个维度进行整体评估，然后给出分数。没有机械的"CRITICAL = -2.0"扣分——那会导致分数虚高和虚假精确。

## 评分范围

每个维度评分 **0.0 – 10.0** — **越高越好**。

| 分数 | 等级 | 含义 |
|------|------|------|
| 9.0-10.0 | S | 优秀，无问题 |
| 8.0-8.9 | A | 良好，有少量小问题 |
| 7.0-7.9 | B | 一般，有一些问题需要修复 |
| 6.0-6.9 | C | 较差，有多个问题需要修复 |
| 5.0-5.9 | D | 差，有严重问题需要修复 |
| 0.0-4.9 | F | 不合格，需要重写 |

## 评分依据

评分基于以下因素：
1. 问题数量
2. 问题严重程度
3. 问题影响范围
4. 修复难度

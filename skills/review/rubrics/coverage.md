# 覆盖度要求

## 原则

审查必须覆盖所有变更的文件。不能跳过任何文件。

## 覆盖度要求

### 必须覆盖

1. **所有变更的文件** — 不能跳过
2. **所有变更的行** — 不能跳过
3. **所有变更的类型** — 不能跳过

### 覆盖度检查

1. **文件覆盖** — 检查是否所有文件都被审查
2. **行覆盖** — 检查是否所有变更行都被审查
3. **类型覆盖** — 检查是否所有文件类型都被审查

## 覆盖度格式

```
## 覆盖度报告

### 文件覆盖
- 变更文件：X 个
- 审查文件：X 个
- 覆盖率：X%

### 行覆盖
- 变更行：X 行
- 审查行：X 行
- 覆盖率：X%
```

## 禁止

1. **禁止跳过文件** — 必须审查所有文件
2. **禁止跳过行** — 必须审查所有变更行
3. **禁止跳过类型** — 必须审查所有文件类型

# 设备与 SDK 变更审查卡

> 仅在 PLC、设备、标刻、SDK、串口、TCP、TX/RX、状态码等场景读取。

## 边界与协议

- 设备通信是否与 UI、控制器和业务编排分层。
- 请求/响应或 TX/RX 报文是否集中解析，未知、空和异常数据是否有失败路径。
- 状态码、状态变化和业务状态转换是否一致，是否可能重复确认或丢失确认。

## 稳定性

- 是否有超时、取消、重试和必要的降级；重试是否幂等。
- 断网、设备离线、延迟、重复反馈和乱序反馈是否处理。
- 资源、连接、事件和后台任务是否释放。

## 数据与日志

- 设备结果回写、事务和幂等是否明确。
- 日志是否记录必要的操作、结果、错误码、耗时和关联 ID。
- 原始报文是否按白名单、脱敏和长度限制记录。

## 验证

- 正常反馈、失败反馈、超时、空报文、异常报文、重复反馈和设备离线均有测试或现场验证证据。
- 验收结论必须关联实际设备/模拟器/接口输出；不能只凭日志存在或代码路径推断成功。

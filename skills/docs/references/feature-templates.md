- **角色**：[具体角色]
- **场景**：[什么时候、什么情况下使用]
- **频率**：[每天/每周/偶尔]

## 功能要求
1. [要求1]
2. [要求2]
3. [要求3]

## 验收标准
- [ ] [标准1 - 可衡量]
- [ ] [标准2 - 可衡量]
- [ ] [标准3 - 可衡量]

## 约束条件
- **时间**：[截止日期]

- **数据**：[数据限制]
- **接口**：[外部依赖]

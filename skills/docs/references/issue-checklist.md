## 常见问题分类

### 功能缺陷
**特征**：功能不工作、报错、结果错误

**排查方向**：
1. 检查代码逻辑
2. 检查输入参数
3. 检查边界条件
4. 检查异常处理

### 性能问题
**特征**：响应慢、超时、资源占用高

**排查方向**：
1. 检查 SQL 查询
2. 检查算法复杂度
3. 检查资源泄漏
4. 检查并发问题

### 数据问题
**特征**：数据错误、数据丢失、数据不一致

**排查方向**：
1. 检查数据来源
2. 检查数据转换
3. 检查事务边界
4. 检查并发冲突

### 接口问题
**特征**：调用失败、超时、返回错误

**排查方向**：
1. 检查请求参数
2. 检查权限配置
3. 检查网络连接
4. 检查服务状态

### 环境问题
**特征**：特定环境出错、配置相关

**排查方向**：
1. 检查配置文件
2. 检查环境变量
3. 检查依赖版本
4. 检查权限设置

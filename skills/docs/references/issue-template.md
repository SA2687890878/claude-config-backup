## 示例

```markdown
# 产线保存失败 - default_production_wh_id 字段缺失

## 基本信息
- **发现日期**：2025-06-05
- **严重程度**：重要
- **状态**：已解决
- **负责人**：胡志军

## 问题现象
调用 SaveLine API 保存产线时，返回 500 错误：
`'PCSGLWorkCenterLine' does not contain a definition for 'DefaultProductionWhId'`

## 环境信息
- **系统**：Windows 11
- **版本**：.NET 8.0
- **数据库**：PostgreSQL

## 复现步骤
1. 打开产线管理页面
2. 点击编辑按钮
3. 修改去向仓库
4. 点击保存

## 预期行为
保存成功，数据库更新 default_production_wh_id 字段

## 实际行为
保存失败，返回 500 错误

## 排查过程

### 第一步：检查错误日志
- **操作**：查看后端日志
- **结果**：发现编译错误
- **结论**：实体类缺少字段定义

### 第二步：检查实体类
- **操作**：查看 PCSGLWorkCenterLine.cs
- **结果**：没有 DefaultProductionWhId 属性
- **结论**：需要添加字段

## 根因分析

### 直接原因
PCSGLWorkCenterLine 实体类缺少 DefaultProductionWhId 属性

### 根本原因
开发时只更新了 Service 层，忘记更新实体类

## 解决方案

### 永久方案
在 PCSGLWorkCenterLine.cs 中添加：
```csharp
[Column("default_production_wh_id", TypeName = "varchar(50)")]
public string DefaultProductionWhId { get; set; } = string.Empty;
```

## 预防措施
1. 修改实体时同步检查所有引用
2. 编译验证后再提交代码
```

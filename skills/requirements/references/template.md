# 需求文档模板

按以下结构输出需求文档，保存到 `requirements-[需求名称简写].md`。

```markdown
# [需求名称]

## 概述
一句话描述需求本质。

## 使用者
- 角色：[具体角色]
- 场景：[什么时候、什么情况下使用]
- 频率：[每天/每周/偶尔]

## 问题与现状
- 当前方案：[描述]
- 痛点：[具体问题]
- 成本：[时间/金钱/错误率]

## 需求规格
### 核心功能（必须）
- [功能点 1]：[具体描述 + 验收标准]
- [功能点 2]：[具体描述 + 验收标准]

### 扩展功能（可选）
- [功能点]

## 成功标准
- [可衡量的指标]

## 约束
- 时间：
- 技术：
- 数据：
- 合规：

## 开放问题
- [还需要确认的问题]
```

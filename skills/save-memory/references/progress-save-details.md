# 保存进度详细流程

在功能开发等长流程中，保存当前进度以便下次继续。

## 写入

保存到 `memory/task-state.md`：

```markdown
---
name: task-state
description: 当前任务进度状态
metadata:
  type: project
---

## 当前任务

- **任务**: [功能名称/bug 描述]
- **阶段**: [当前在哪个 Phase]
- **下一步**: [具体要做什么]

## 已完成

- [x] Phase 1: 需求探索 — [简述结果]
- [x] Phase 2: 实现规划 — [计划文件路径]
- [ ] Phase 3: 代码实现 — 进行中

## 关键上下文

- 涉及文件：[文件列表]
- 设计决策：[关键决策]
- 已知问题：[遇到的问题]

## 恢复指令

下次会话输入"继续工作"即可恢复。
```

## 自动保存

在以下时机自动建议保存进度：
- 长流程的每个 Phase 完成时
- 用户说"先到这"、"下次继续"时
- 会话即将结束时

# 来源分类与目录映射

## 映射规则

| 来源特征 | 目录 |
|---|---|
| `mp.weixin.qq.com` | `01-精读笔记/公众号/` |
| 博客（知乎/掘金/medium/dev.to 等） | `01-精读笔记/博客/` |
| 官方文档（docs.xxx.com/RFC/GitHub wiki） | `01-精读笔记/技术文档/` |
| GitHub 仓库（README/整体分析） | `01-精读笔记/开源项目/` |
| 本地 PDF/书籍 | `01-精读笔记/书籍/` |
| 其他/不确定 | `00-收件箱/` |

## 判断逻辑

1. 检查 URL 域名匹配上表
2. URL 无法判断时，检查内容特征（有代码=技术文档，有章节=书籍）
3. 仍无法判断 → 放 `00-收件箱/`，标记 `status: "inbox"`

## 目录不存在时

自动创建缺失的子目录。

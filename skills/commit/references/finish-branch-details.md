# 完成分支详细流程

## 验证测试

```bash
dotnet test / npm test
```

测试失败：停下，不继续。

## 检测环境 + 呈现选项

检测当前环境（是否在 worktree、是否有未提交变更等），向用户呈现选项：

| 选项 | 合并 | 推送 | 保留 Worktree | 清理分支 |
|------|------|------|---------------|---------|
| 1. 本地合并 | 是 | - | - | 是 |
| 2. 创建 PR | - | 是 | 是 | - |
| 3. 保持现状 | - | - | 是 | - |
| 4. 丢弃 | - | - | - | 是（force） |

## 执行

根据用户选择执行相应操作。

## 清理

如果选择清理分支，执行：
```bash
git branch -d <branch-name>  # 删除本地分支
git push origin --delete <branch-name>  # 删除远程分支（可选）
```

# 常见测试失败模式

## 编译错误

**症状：** `Build FAILED`，测试根本没运行
**根因：** 代码有语法错误、引用缺失、类型不匹配
**修复：** 先修编译错误，再跑测试

## 断言失败

**症状：** `Assert.Equal()` / `Assert.True()` 失败
**根因：** 实际值和预期值不一致
**修复：** 对比 actual vs expected，找出差异原因

## 空引用异常

**症状：** `NullReferenceException`
**根因：** 对象未初始化、mock 未设置、依赖注入缺失
**修复：** 检查 mock 设置、依赖注入配置、null 检查

## 异步死锁

**症状：** 测试超时、卡住不动
**根因：** `.Result` / `.Wait()` 阻塞了同步上下文
**修复：** 全链路 async/await，不用 .Result

## 数据库相关

**症状：** 连接失败、表不存在、约束冲突
**根因：** 测试数据库未初始化、迁移未执行、测试数据污染
**修复：** 用 InMemory 数据库或确保每个测试有独立数据

## Mock 相关

**症状：** `Mock verification failed`、返回值不对
**根因：** Setup 参数不匹配、Returns 设置错误
**修复：** 检查 Setup 的参数匹配条件和返回值

## 并发相关

**症状：** 偶尔失败、不稳定
**根因：** 共享状态、测试顺序依赖、竞态条件
**修复：** 消除共享状态，每个测试独立运行

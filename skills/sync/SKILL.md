# 同步管理

## 核心原则

**用户说"同步"，agent 自动判断同步什么。**

## 路由

| 意图 | 策略 |
|------|------|
| 同步经验（"同步经验"、"同步知识"、"更新知识库"） | → A. 经验同步 |
| 同步源码（"同步源码"、"刷新索引"、"重新索引"） | → B. 源码索引同步 |
| 不确定 | → 询问用户 |

---

## A. 经验同步

**适用场景：** 同步项目经验到知识库。

**核心流程：**
1. 读取 `references/sync-details.md` 了解详细流程
2. 收集项目中的 learnings
3. 分类判断（工程/项目/业务）
4. 用户确认
5. 写入 Knowledge
6. 标记已同步

**输出格式：**
```
## 知识同步报告

### 同步统计
- 总计：X 条经验
- 已同步：X 条
- 跳过：X 条

### 同步明细
- knowledge/engineering/xxx.md
- knowledge/project/xxx.md
- knowledge/business/xxx.md

### learnings.md 更新
已标记 X 条经验为"已同步"
```

---

## B. 源码索引同步

**适用场景：** 同步加密源码到可读副本并重建索引。

**核心流程：**
1. 读取 `scripts/convert-source.ps1` 了解转换脚本
2. 同步加密源码到可读副本
3. 重建 context-mode 索引
4. 验证索引完整性

**输出格式：**
```
## 同步报告

### 同步内容
- 类型：源码索引同步
- 范围：项目级

### 结果
- 同步文件：X 个
- 重建索引：X 个

### 验证
- ✅ 索引完整性检查通过
- ✅ 搜索测试通过
```

## 同步原则

### 必须做的

1. **同步前备份** — 确保可以回滚
2. **同步后验证** — 确保同步成功
3. **记录日志** — 记录同步内容和结果

### 禁止做的

1. **禁止覆盖未备份** — 必须先备份
2. **禁止跳过验证** — 必须验证同步结果
3. **禁止记录敏感信息** — 不记录密钥/密码

## 完成标准

- [ ] 同步内容已自动判断（经验同步 / 源码索引同步），不确定时已询问
- [ ] 同步前已备份，可回滚
- [ ] 经验同步（A）：learnings 已分类（工程/项目/业务）经用户确认写入 Knowledge，并标记"已同步"
- [ ] 源码索引同步（B）：转换脚本已跑、索引已重建、完整性检查通过（搜索测试通过）
- [ ] 输出同步报告（同步统计/明细/验证结果），未记录敏感信息
- [ ] 与会话级沉淀边界正确：临时经验沉淀走 `/save-memory`，本 skill 只做批式知识/索引同步

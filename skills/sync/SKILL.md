# 同步管理

## 核心原则

**用户说"同步"，agent 自动判断同步什么。**

## 路由

| 意图 | 策略 |
|------|------|
| 同步经验（"同步经验"、"同步知识"、"更新知识库"） | → A. 经验同步 |
| 同步源码（"同步源码"、"刷新索引"、"重新索引"） | → B. 源码索引同步 |
| 不确定 | → 询问用户 |

---

## A. 经验同步

**适用场景：** 同步项目经验到知识库。

**核心流程：**
1. 收集项目中的 learnings
2. 整理到 `~/.claude/learnings.md`
3. 更新知识库索引

**输出格式：**
```
## 同步报告

### 同步内容
- 类型：经验同步
- 范围：项目级 / 全局级

### 结果
- 同步项目：X 个
- 更新文件：X 个
- 新增条目：X 个
```

---

## B. 源码索引同步

**适用场景：** 同步加密源码到可读副本并重建索引。

**核心流程：**
1. 同步加密源码到可读副本
2. 重建 context-mode 索引
3. 验证索引完整性

**输出格式：**
```
## 同步报告

### 同步内容
- 类型：源码索引同步
- 范围：项目级

### 结果
- 同步文件：X 个
- 重建索引：X 个

### 验证
- ✅ 索引完整性检查通过
- ✅ 搜索测试通过
```

---

## 同步原则

### 必须做的

1. **同步前备份** — 确保可以回滚
2. **同步后验证** — 确保同步成功
3. **记录日志** — 记录同步内容和结果

### 禁止做的

1. **禁止覆盖未备份** — 必须先备份
2. **禁止跳过验证** — 必须验证同步结果
3. **禁止记录敏感信息** — 不记录密钥/密码

Git 提交信息生成。遵循公司规范，生成标准化的提交信息。

## 执行步骤

1. **分析变更**
   ```bash
   git status
   git diff --stat
   git diff --cached --stat
   ```

2. **确定提交类型**
   根据 `rules/git.md` 中的类型列表选择：
   - 新增功能 → `新增`
   - 修复 bug → `修复`
   - 文档修改 → `文档`
   - 代码重构 → `重构`
   - 性能优化 → `优化`
   - 测试代码 → `测试`
   - 配置变更 → `配置`
   - 代码回滚 → `回滚`

3. **生成提交信息**
   格式：
   ```
   [类型] 简短描述（5~100 字符）

   详细描述（至少 10 个字符，可多行）

   关联 Issue #编号（可选）
   ```

4. **确认并提交**
   - 展示生成的提交信息
   - 用户确认后执行 `git commit`

功能开发流程。从需求到交付的完整开发流程。

## 执行方式

使用 Workflow 工具执行：

```
Workflow({scriptPath: "~/.claude/workflows/build.js"})
```

## 参数

- `featureName` — 功能名称（必需）
- `requirementDoc` — 需求文档路径（可选）
- `decisionDoc` — 决策记录路径（可选）

## 核心原则（每次必读）

1. 修改配置后必须运行验证（`node hook.js` 测试）
2. 不要硬编码路径，从 `input.cwd` 动态生成
3. 所有 catch 块必须有错误输出
4. readStdin 超时时 resolve 已接收数据（不是空字符串）
5. HOME 环境变量必须有 fallback（`|| ''`）

## 代码修改经验

### sed/PowerShell 字符串转义坑

**问题**：`'\n'`、`'\r'`、`'\t'` 在 shell sed 替换中会被展开成实际字符，而不是 JavaScript/代码中的转义字符。

**后果**：`split('\n')` 变成 `split('` + 实际换行 + `')`，导致语法错误。

**正确做法**：
- 涉及特殊字符的代码修改，用 `git cherry-pick` 或直接 Read/Edit 精确修改
- 不要用 sed/PowerShell 的字符串替换处理转义字符

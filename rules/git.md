# Git 规范

## 分支命名

格式：`前缀/名称`

| 英文前缀 | 中文前缀 | 说明 |
|---------|---------|------|
| `feature` / `feat` | `新增` | 新功能开发 |
| `fix` / `bugfix` | `修复` | 普通 bug 修复 |
| `hotfix` | `热修复` | 紧急线上问题修复 |
| `docs` | `文档` | 文档类修改 |
| `refactor` | `重构` | 代码重构，不改变功能 |
| `test` | `测试` | 增加或修改测试代码 |
| `chore` | `配置` | 构建、工具、依赖等配置变更 |
| `优化` | `优化` | 性能或体验优化 |
| `回滚` | `回滚` | 代码回滚操作 |

### 示例
```
feature/user-login
feat/用户登录模块
fix/订单金额计算错误
hotfix/支付超时紧急修复
refactor/数据库连接池优化
```

## 提交信息

格式：
```
[类型] 简短描述（5~100 字符）

详细描述（至少 10 个字符，可多行）

关联 Issue #编号（可选）
```

类型：`新增`、`修复`、`文档`、`重构`、`优化`、`测试`、`配置`、`回滚`

### 示例
```
[新增] 增加用户登录功能

实现手机号+验证码登录方式，对接短信服务商接口，增加登录态缓存逻辑。

关联 Issue #245
```

## 禁止操作

- 禁止直接 push 到 main/master

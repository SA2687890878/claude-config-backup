# 工作流触发规则

> 触发词映射唯一定义处。CLAUDE.md 引用此文件。详细流程见各 command 文件。

## 新会话启动

检查 memory，回忆上次进度。用户意图"继续工作"时，执行 `git status` 输出状态摘要。

## 触发条件

用户明确要求执行操作时触发。讨论/分析/了解时不触发。

## 触发词 → 命令映射

| 触发词 | 命令 | 说明 |
|--------|------|------|
| 讨论/设计/方案/头脑风暴 | `/brainstorming` | 需求探索 → 设计规格（不写代码） |
| 开发/添加/实现 | `/feature-development` | 功能开发全流程（含 brainstorming） |
| 修复/bug/报错 | `/bug-fix` | Bug 修复流程 |
| 优化/慢/性能 | `/perf-optimize` | 性能优化流程 |
| 审查/review | `/code-review` | 代码审查流程 |
| 提交 | `/commit` | Git 提交信息生成 |
| 开始/继续 | 直接触发 | git status + task list |
| 文档（项目/功能/排查） | `docs` skill | scope 路由到项目/功能/问题级 |

## 完成检查点

每个流程结束后输出：
- **变更文件**: [列表]
- **变更内容**: [一句话]
- **下一步**: [建议]

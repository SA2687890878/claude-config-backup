# 记忆生命周期（进-留-出）

> 目的：记忆不无限膨胀、只注入相关的——**省 token 的长期关键**。
> 对象：DSH memory 五轨（key/user/memory/project/daily）+ 项目 `learnings.md`。
> 按需加载，不自动注入。

## 进（写入）

| 内容 | 轨 | 说明 |
|------|-----|------|
| 关键决策/约定/踩坑/长期事实 | `key` | 自动注入，最高价值，谨慎写 |
| 用户偏好/身份事实 | `user` | 自动注入 |
| 项目环境/通用事实 | `memory` | 跨项目 |
| 项目进展/本轮结论 | `project` | 每轮收尾写 |
| 当日日志 | `daily` | 每轮收尾写 |

## 留（标注）

- `key` 轨只写 `[重要]` 级内容，平凡琐事不写 key
- 时间敏感信息带日期 `YYYY-MM-DD`
- 每条一句话；细节进知识库文件，记忆只留指针

## 标注规范（写 key / memory 时）
- **类型 mtype**：`constraint` 硬约束(召回即照做) / `decision` 已敲定方案(召回即复用) / `preference` 稳定口味(召回即沿用) / `fact` 事实(跳过重推导) / `event` 事件 / `risk` 风险
- **置信度 cf**：`1.0` 用户原话或已批准；`0.8` 用户明确倾向；`0.6` AI 推断（不得当成用户确定事实）
- **有效期 valid_until**：临时决策 / 一次性结论必须标 `YYYY-MM-DD`，到期不作当前事实；长期规则留空
- **纠错 supersede**：新事实推翻旧事实时改写新条，旧原文保留在归档 / learnings 供溯源，不硬删
- **原子性**：一条记忆 = 恰好一个事实；禁止用 `；` / `且` / `并且` 拼接多事实 → 拆开写。"操作列用按钮且列宽可拖且刷新不重置"须拆成三条。

## 出（召回）

- 只依赖自动注入快照（key/user/关键记忆），不主动读全量
- 需要查时用 `memory list` + `filter/since/limit/recent` 精确查，**禁止 list 全部**
- 查不到换过滤词，不硬翻

### 召回操作语义（召回即约束，不重问不重选）
- `constraint`（硬约束）→ 用户没重申也照做
- `decision`（已定方案）→ 直接复用既有选型
- `fact`（已知事实）→ 跳过重推导，不再向用户确认
- 新记录标"沿用 <既有决策>"而非"新增"，避免记忆膨胀

## 淘汰（归档）

- 低频旧事：`archive` 移入归档文件（可逆、不注入但保留）
- 项目完结/方案废弃：归档相关 key/project 条目
- 90 天未引用且无未来价值：归档
- 归档后索引不再出现，可查回

## 反模式

- 不重复记录已归档内容
- 不为仪式感写空条目
- daily/project 只记"结论+证据+坑"，不堆流水账

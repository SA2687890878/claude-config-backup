# Git 规范

## 分支命名

格式：`前缀/名称`

| 前缀 | 说明 |
|------|------|
| `feature` / `feat` | 新功能 |
| `fix` / `bugfix` | 普通 bug 修复 |
| `hotfix` | 紧急线上问题 |
| `docs` | 文档修改 |
| `refactor` | 代码重构 |
| `test` | 测试代码 |
| `chore` | 构建/工具/依赖配置 |

示例：`feature/user-login`、`fix/订单金额计算错误`

## 提交信息

格式：
```
[类型] 简短描述（5~100 字符）

详细描述（至少 10 个字符）

关联 Issue #编号（可选）
```

类型：`新增`、`修复`、`文档`、`重构`、`优化`、`测试`、`配置`、`回滚`

## 禁止操作

- 禁止直接 push 到 main/master
- 先建分支再提交

# Test Gate

**时机**：测试完成后，进入发布阶段前

## 检查项

### 测试通过
- [ ] `dotnet test` 退出码 == 0
- [ ] 所有测试通过（0 失败）
- [ ] 无跳过的测试（或已说明原因）

### 覆盖率
- [ ] 主流程测试覆盖
- [ ] 异常流程测试覆盖
- [ ] 边界条件测试覆盖

### 回归
- [ ] 现有测试无回归
- [ ] 新增功能有对应测试
- [ ] 修复的 bug 有复现测试

## 通过条件
- 所有测试通过
- 覆盖率达标（视项目要求）
- 无回归

## 失败处理
- 返回测试阶段补充测试
- 记录失败测试，要求修复

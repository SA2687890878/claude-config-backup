# Requirement Gate

**时机**：需求探索完成后，进入设计阶段前

## 检查项

### 完整性
- [ ] 功能需求是否明确（不是"用户觉得..."）
- [ ] 验收标准是否可衡量（Given/When/Then）
- [ ] 边界条件是否定义（正常/异常/边界值）
- [ ] 约束条件是否列出（技术/业务/时间）

### 无歧义
- [ ] 术语是否统一（同一概念只用一个词）
- [ ] 需求是否可测试（能写测试用例验证）
- [ ] 需求是否可实现（技术上可行）

### 可验收
- [ ] 验收标准是否具体（不是"用户体验好"）
- [ ] 验收标准是否自动化（能用代码验证）
- [ ] 验收标准是否完整（覆盖所有功能点）

## 通过条件
- 所有检查项都通过
- 用户确认需求文档

## 失败处理
- 返回需求探索阶段补充信息
- 记录缺失项，要求用户补充

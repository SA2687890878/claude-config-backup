# Code Gate

**时机**：编码完成后，进入测试阶段前

## 检查项

### 编译通过
- [ ] `dotnet build --configuration Release` 退出码 == 0
- [ ] 无编译错误
- [ ] 无编译警告（可选，视项目配置）

### 代码审查通过
- [ ] 无 CRITICAL 问题
- [ ] 无 HIGH 问题（或已标记为可接受）
- [ ] MEDIUM 问题已评估风险

### 代码质量
- [ ] 命名符合项目规范
- [ ] 方法长度合理（<50 行）
- [ ] 无重复代码
- [ ] 异常处理完善

### 安全性
- [ ] 无 SQL 注入风险
- [ ] 无 XSS 漏洞
- [ ] 无硬编码密钥
- [ ] 权限校验正确

## 通过条件
- 编译通过
- 代码审查通过（无 CRITICAL/HIGH）
- 安全扫描通过

## 失败处理
- 返回编码阶段修复
- 记录问题，要求开发者修复

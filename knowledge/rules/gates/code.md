# Code Gate

**时机**：编码完成后，进入测试阶段前

## 检查项

### 编译通过
- [ ] `dotnet build --configuration Release` 退出码 == 0
- [ ] 无编译错误
- [ ] 无编译警告（可选，视项目配置）

### 代码审查通过
- [ ] 无 CRITICAL 问题
- [ ] 无 HIGH 问题（或已标记为可接受）
- [ ] MEDIUM 问题已评估风险

### 代码质量
- [ ] 命名符合项目规范
- [ ] 方法长度合理（<50 行）
- [ ] 无重复代码
- [ ] 异常处理完善

### 安全性
- [ ] 无 SQL 注入风险
- [ ] 无 XSS 漏洞
- [ ] 无硬编码密钥
- [ ] 权限校验正确

## 通过条件
- 编译通过
- 代码审查通过（无 CRITICAL/HIGH）
- 安全扫描通过
- 深度审计通过（触发时）

## 深度审计触发

当满足以下任一条件时，自动触发 Fuck_My_Shit_Mountain 审计：

### 自动触发条件
1. **代码量触发**
   - 新增/修改 > 100 行代码
   - 修改 > 5 个文件

2. **安全触发**
   - 涉及认证/授权代码（auth, permission, security）
   - 涉及加密操作（crypto, encrypt, decrypt）
   - 涉及数据库查询（query, sql, database）

### 审计执行
```bash
/audit --mode quick
```

### 审计结果处理
- [ ] 无 CRITICAL 问题
- [ ] HIGH 问题已修复或标记为可接受
- [ ] 评分 >= 7.0/10

## 失败处理
- 返回编码阶段修复
- 记录问题，要求开发者修复
- 审计发现问题阻断进入测试阶段

# Release Gate

**时机**：发布前，部署到生产环境前

## 检查项

### 风险评估
- [ ] 变更范围评估（影响哪些模块）
- [ ] 数据风险评估（是否有数据迁移）
- [ ] 性能风险评估（是否有性能影响）
- [ ] 安全风险评估（是否有安全漏洞）

### 回滚方案
- [ ] 回滚步骤是否明确
- [ ] 回滚时间是否可接受
- [ ] 数据回滚是否可行

### 发布方案
- [ ] 发布步骤是否明确
- [ ] 发布时间是否合适（避开高峰期）
- [ ] 监控方案是否就绪

### 文档
- [ ] 变更日志是否更新
- [ ] API 文档是否更新（如有接口变更）
- [ ] 用户文档是否更新（如有功能变更）

## 通过条件
- 所有检查项都通过
- 深度审计通过
- 用户确认发布

## 深度审计（发布前必做）

发布前必须执行 Fuck_My_Shit_Mountain 完整审计：

### 审计执行
```bash
/audit --mode full
```

### 审计通过条件
- [ ] 无 CRITICAL 问题
- [ ] HIGH 问题已全部修复
- [ ] 评分 >= 7.0/10
- [ ] 安全审计通过（security 模式）

### 审计报告
- 审计报告存档到 `.claude/audits/` 目录
- 关键发现记录到发布清单

## 失败处理
- 返回对应阶段修复
- 记录风险，要求制定缓解措施
- 审计不通过阻断发布

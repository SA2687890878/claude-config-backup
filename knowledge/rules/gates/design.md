# Design Gate

**时机**：设计完成后，进入编码阶段前

## 检查项

### 满足需求
- [ ] 设计是否覆盖所有功能需求
- [ ] 设计是否满足非功能需求（性能/安全/可用性）
- [ ] 设计是否符合约束条件

### 可扩展性
- [ ] 模块划分是否合理（单一职责）
- [ ] 依赖方向是否正确（高层不依赖低层）
- [ ] 接口设计是否稳定（不易频繁变更）

### 性能风险
- [ ] 是否有 N+1 查询风险
- [ ] 是否有大数据量处理
- [ ] 是否有并发安全问题

### 数据风险
- [ ] 数据库设计是否符合范式
- [ ] 索引设计是否合理
- [ ] 数据迁移方案是否可行
- [ ] 外部调用是否定义超时、取消、重试、降级和幂等（涉及才检查）
- [ ] 权限、数据隔离、异常路径和版本兼容是否明确
- [ ] 数据库或配置变更是否有可执行的回滚方案

## 通过条件
- 所有检查项都通过
- 架构审查通过（无 CRITICAL/HIGH 问题）

## 失败处理
- 返回设计阶段修改
- 记录问题，要求设计者修复

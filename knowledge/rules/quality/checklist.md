# Requirement 微清单（10 行自检）

> 按需加载。意图/需求落盘前逐项勾选，过不了不进 Design Gate。

- [ ] 约束：时间/技术/数据/合规 各1行已写（无“TBD/待定”）
- [ ] 非目标：明确 1-3 条“不做什么”
- [ ] 安全/隐私：密钥/权限/数据范围 已写 1 行
- [ ] 验收：可量化（数字/用例/接口）而非“好用/更快”
- [ ] 范围：改哪些模块/文件/接口 已圈定
- [ ] 术语：关键名词已统一，无一词多义
- [ ] 依赖：外部/数据/上下游依赖已列
- [ ] 风险：失败回退与不做的影响 已写 1 行
- [ ] 产物：Requirement.md 路径 = `active.json product_path`
- [ ] 证据：需求与验收已获用户确认（口头/书面）

# 验证纪律

## 验证纪律（确定性，不允许主观放宽）

### 退出码为王
- 只看退出码，不看 agent 自述
- 退出码 == 0 就是 PASS
- 退出码 != 0 就是 FAIL，没有"应该通过"

### 必须运行命令
- 不能声称成功但没有实际运行
- 必须给出实际运行的命令和返回内容

### 必须给出证据
- 实际运行的命令
- 实际返回的内容
- 不能用"应该通过"或"理论上没问题"

### 不主观放宽
- 退出码 != 0 就是 FAIL，没有例外
- 不能因为"看起来没问题"就认为通过

## How to apply

- 每次验证都必须遵守这些纪律
- 退出码是唯一的判定标准
- 必须给出实际运行的证据

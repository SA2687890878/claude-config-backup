# Business Knowledge（业务知识）

本目录存放业务相关的知识，包括：

## 目录结构

```
business/
├── domain/          # 领域知识（业务领域、专业术语）
├── workflows/       # 业务流程（审批流程、操作流程）
├── rules/           # 业务规则（校验规则、计算规则）
└── glossary/        # 术语表（业务术语、缩写解释）
```

## 存放内容

### 领域知识（domain/）
- 业务领域概述
- 核心业务概念
- 领域模型说明

### 业务流程（workflows/）
- 审批流程
- 操作流程
- 状态流转

### 业务规则（rules/）
- 数据校验规则
- 金额计算规则
- 权限控制规则

### 术语表（glossary/）
- 业务术语定义
- 缩写全称对照
- 行业专有名词

## 命名规范

- 文件名：`{业务模块}-{知识点}.md`
- 示例：`order-discount-calculation.md`
- 示例：`user-authentication-flow.md`

## 与 Memory 的区别

| 类型 | 存放内容 | 示例 |
|------|---------|------|
| **Memory** | 决策、约束、进度 | "选择方案 A 因为..." |
| **Knowledge/Business** | 业务知识、规则、流程 | "订单折扣计算规则" |

## Why:
业务知识需要持久化保存，方便跨会话复用，避免重复解释。

## How to apply:
遇到需要反复解释的业务概念、规则、流程时，保存到本目录。

# 索引设计原则

索引文件（INDEX.md / MEMORY.md）先定读者，再定内容：**给 Claude 读的只留索引，给人看的放 docs/。**

## 两种文档类型

### 1. 给 Claude 读取的索引
- **目的**：告知可用资源，支持按需加载
- **内容**：名称、路径、一句话说明
- **禁止**：统计信息、优先级、使用方法、详细说明
- **格式**：表格 + 绝对路径
- **位置**：`knowledge/*/INDEX.md`、`knowledge/MEMORY.md`

### 2. 给人看的文档
- **目的**：帮助理解和使用系统
- **内容**：详细说明、示例、使用方法（不受限制）
- **位置**：`docs/`

## 判断标准
- 读者是 Claude → 只留「名称/路径/一句话」
- 读者是人 → 放 docs/，可写详细
- 索引里混入教程 = 违规（浪费每次加载的 token）；docs 里塞无用索引 = 噪音

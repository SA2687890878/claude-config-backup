# 索引设计原则

## 问题

索引文件（如 INDEX.md、MEMORY.md）应该包含什么内容？

## 两种文档类型

### 1. 给 Claude 读取的索引

**目的**：告诉 Claude 有哪些资源可用，方便按需加载

**特点**：
- 只包含索引内容（名称、路径、简短说明）
- 不包含详细说明、示例、使用方法
- 格式简洁，易于解析

**例子**：
```markdown
# Rules 索引

## 核心规则（自动加载）
| Rule | 路径 |
|------|------|
| 代码访问 | `~/.claude/rules/tools/code-access.md` |
| ... | ... |

## 参考规则（按需加载）
| Rule | 路径 |
|------|------|
| 加密机制 | `~/.claude/knowledge/rules/code-access/encryption.md` |
| ... | ... |
```

**存放位置**：
- `~/.claude/knowledge/MEMORY.md` - 知识库索引
- `~/.claude/knowledge/rules/INDEX.md` - 规则索引

### 2. 给人看的文档

**目的**：帮助用户理解和使用系统

**特点**：
- 包含详细说明、示例、使用方法
- 包含统计信息、优先级说明
- 格式丰富，易于阅读

**例子**：
```markdown
# Rules 使用指南

## 统计信息
- **总计**：18 个 Rules
- **核心规则**：4 个（自动加载）
- **参考规则**：14 个（按需加载）

## 优先级
项目级 .claude/rules/ > 全局 ~/.claude/rules/ > 项目级 CLAUDE.md

## 使用方法
### 方式 1：通过 ctx_search 查询
### 方式 2：通过 Read 工具读取
### 方式 3：通过 CLAUDE.md 引用
```

**存放位置**：
- `~/.claude/docs/` - 人类文档中心

## 设计原则

### 给 Claude 读取的索引

1. **只保留索引内容**：
   - 名称
   - 路径
   - 简短说明（一句话）

2. **不包含的内容**：
   - ❌ 统计信息
   - ❌ 优先级说明
   - ❌ 使用方法
   - ❌ 详细说明

3. **格式要求**：
   - 使用表格格式
   - 路径使用绝对路径
   - 说明简洁明了

### 给人看的文档

1. **可以包含的内容**：
   - ✅ 详细说明
   - ✅ 统计信息
   - ✅ 使用方法
   - ✅ 示例代码

2. **格式要求**：
   - 使用 Markdown 格式
   - 结构清晰
   - 包含目录

## 示例对比

### 错误示例（给 Claude 读取的索引包含给人看的内容）

```markdown
# Rules 索引

## 统计信息
- **总计**：18 个 Rules
- **核心规则**：4 个（自动加载）
- **参考规则**：14 个（按需加载）

## 优先级
项目级 .claude/rules/ > 全局 ~/.claude/rules/ > 项目级 CLAUDE.md

## 使用方法
### 方式 1：通过 ctx_search 查询
### 方式 2：通过 Read 工具读取

## 规则列表
| Rule | 路径 |
|------|------|
| 代码访问 | `~/.claude/rules/tools/code-access.md` |
```

### 正确示例（给 Claude 读取的索引只保留索引）

```markdown
# Rules 索引

## 核心规则（自动加载）
| Rule | 路径 |
|------|------|
| 代码访问 | `~/.claude/rules/tools/code-access.md` |
| ... | ... |

## 参考规则（按需加载）
| Rule | 路径 |
|------|------|
| 加密机制 | `~/.claude/knowledge/rules/code-access/encryption.md` |
| ... | ... |
```

## How to apply

- 创建索引文件时，先确定目标受众（Claude 还是人）
- 给 Claude 读取的索引：只保留索引内容
- 给人看的文档：放在 docs/ 目录
- 不要在索引文件中包含给人看的内容

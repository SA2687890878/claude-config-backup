# PCS 数采测试矩阵

> 设备、标刻、SDK、采集和跨基地功能测试时按变更范围选择，不要求每次全量执行。

| 维度 | 必查场景 | 证据 |
|---|---|---|
| 设备 | 在线、离线、连接失败、未知状态 | 模拟器/现场反馈、错误码 |
| 反馈 | 成功、失败、超时、空报文、异常报文、重复/乱序反馈 | 请求响应、状态转移、日志 |
| 网络 | 断网、弱网、重连、请求超时 | 重试次数、最终状态、用户提示 |
| SDK | 成功、业务失败、空 Data、错误 Message、接口超时 | 返回摘要、错误码、耗时 |
| 数据 | 空条码、重复条码、数量不一致、结果回写失败 | 数据库前后状态 |
| 并发 | 重复点击、重复工单、同一条码并发处理 | 幂等结果、无重复写入 |
| 数据库 | 事务回滚、部分写入失败、分区表不存在/选错 | 事务结果、回滚后数据 |
| 时间 | 跨日、跨时区、公历/佛历规则、月份分表 | 计算结果、分区命中 |
| 日志 | 调用链完整、TX/RX 可关联、敏感字段脱敏、远程失败本地兜底 | 日志检索和文件 |
| UI | 耗时操作不阻塞、成功/失败/超时提示、重复操作防护 | 操作前后状态、运行证据 |

## 判定规则

- 核心路径必须有可运行证据，不能只看代码或日志存在。
- 外部设备不可用时，必须明确使用模拟器、录制响应或人工现场验证，并标注未覆盖项。
- 发现部分成功时，验证业务状态、数据库状态、设备状态和日志是否一致。
